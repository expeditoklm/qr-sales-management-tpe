Webhook QuickSellPay

  • /api/webhook/sale pour recevoir les ventes caisse.
  • /billing/fedapay/webhook pour FedaPay.
  • Verifier les secrets, les firewalls et le HTTPS public.

Configuration API

Base URL recommandee pour web et mobile :
  • /health pour tester la disponibilite.
  • /docs pour Swagger.
  • /redoc pour la documentation Redoc.
  • Centraliser l'URL backend pour toutes les boutiques avant diffusion.
